# 服务连续性与空闲切换

中文 | [English](service-continuity.md) · [返回文档索引](README.md)

本文说明 `mindie-agent-cc` 后台知识服务的归属校验、隔离小模型调用与版本更新时的连续性保障。

## 1. 精确服务归属与复用

- 知识 MCP 请求与 `Stop` 准入通过共享 `mindie-knowledge` 核心的就绪服务路径连接后台工作器。
- 复用现有服务要求完整配置指纹、活动安装绑定与工作器健康状态全部匹配；仅端口可达但属于旧配置世代的端点不会被误用，核心报告归属未知或失败时适配器绝不私自启动第二个竞争工作器。

## 2. 隔离的原生模型整理调用

- 在生成分块检索导航时，Claude Code 适配器仅从选定原生配置中提取受支持的 Provider / Model / Effort 设置注入隔离的整理进程，不导入用户的 Hook、MCP、工具或项目级自定义指令，且绝不将密钥写入状态回执。

## 3. 验收边界

- 本地守护进程与实机验收覆盖活跃、缺失、撤权与更新切换路径（包括 macOS `2.1.269`、原生 Windows 与 WSL `2.1.299`），验证在途任务租约保留、新旧服务平滑交接及停用后的进程与配置清理。
