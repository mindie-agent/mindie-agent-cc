# mindie-agent-cc 0.1.30: Great Subtraction and Install UX Upgrade

[中文](mindie-agent-cc-0.1.30.md)

- **Great Subtraction**: Deleted 40 legacy duplicate runtime modules so `scripts/` retains only 8 thin files (`__init__`, `plugin_entry`, `session_start`, `mindie_launch`, `entry`, `host_adapter`, `transcript`, `setup`) with total Python LOC under 1,200. MCP, hooks, sharing, updates, RSI, and locking now delegate to `mindie-harness` (`API_VERSION = 1`), while the bundled `assets/{mindie-harness-seed.pyz, seed-lock.json}` keeps cold start deterministic.
- **Zero-inline launch and strict MCP surface separation**: `hooks/hooks.json` and `.mcp.json` invoke the file-based `scripts/plugin_entry.py` with zero `python -c` blobs. `knowledge` exposes only the 5 `knowledge_*` tools; `remote` exposes only the 13 `claude` `remote_*` tools (zero `remote_BashOutput` / `remote_KillShell`); `components` exposes only component tools and zero `knowledge_*`. `Stop` exits quietly in `< 30ms` with zero SQLite when unconfigured, disabled, or out of scope, using same-drive `os.path.commonpath` matching so `/work/app-other` never matches `/work/app`.
- **Install and onboarding UX**: `uv run https://github.com/mindie-agent/mindie-agent/releases/latest/download/install.py --host cc` installs and warms the runtime in one command. `gh` is optional and never blocks installation (missing or logged out automatically recommends `local-only`). First-run onboarding presents three dynamic `gh`-aware `AskUserQuestion` prompts—workspace, community sharing (`contribute` recommended when `gh` is authenticated, otherwise `local-only`), and a one-step SSH NPU connection (terminal mode may finish with a hidden `--password` login)—followed by one polite Star line. A read-only `mindie_doctor` readiness check reports a concrete error once and never blocks the task.
- **Tests and release validation**: `tests/` is rebuilt as a fast, isolated thin-plugin contract suite covering manifests/seed and `release-metadata`, hook fast paths, strict MCP tool-surface separation, `setup.py sharing`/`doctor` delegation, and transcript fork `queue-operation` `enqueue` boundaries, sidechain/thinking/`<command-...>` filtering, and `[start, end)` SHA-256 accounting. `setup.py release-metadata` still validates every AST symbol, test ID, and local evidence file in `harness-compatibility.json`.
