# mindie-agent-cc 0.1.29: Silent Default-On Architecture and Zero Pre-Call Session-Binding Gates

[中文](mindie-agent-cc-0.1.29.md)

- **Default-Enabled `knowledge_*` MCP & Zero Pre-Call Binding Gate**: Exposes `knowledge_query`, `knowledge_explain`, `knowledge_feedback`, `knowledge_distill`, `knowledge_sync`, and `mindie_status` on the `knowledge` MCP surface on startup, removes mandatory `PreToolUse` nonce gates and manual slash-command activation prerequisites, resolves session identity via optional `claim_bind` hints falling back cleanly to `_CONNECTION_SESSION_ID` across main chats, Claude Code `Task` subagents, and forks, auto-provisions default session leases (`not_before=0.0`) on demand when required, and preserves Receipt Honesty (`receipt_warning` + `receipt_unconfirmed=True`) alongside dedicated `read_pool` concurrency for `readOnlyHint=True` tools.
- **Lightweight Passive Hooks & Consent-First `Stop` Fast-Path**: Removes `UserPromptExpansion` slash-command matchers from `hooks/hooks.json` and keeps `PreToolUse` and `SessionStart` passive and SQLite-free when unconfigured; updates `Stop` to verify `mindie-consent.json` and authorized `project_roots` before opening `admission.sqlite3` or spawning capture workers—exiting in `< 100ms` with zero SQLite files created when unconfigured, disabled, or out of scope, and auto-ensuring the session lease when authorized.
- **Silent Semantic `SKILL.md` (`user-invocable: false`)**: Sets `user-invocable: false` in `skills/mindie-agent/SKILL.md` frontmatter so Claude Code loads Ascend NPU, vLLM-Ascend, xLLM, MindIE-SD, AscendC, Triton, and CANN engineering guidance semantically without exposing manual slash commands, and updates bilingual documentation accordingly.
