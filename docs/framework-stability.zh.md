# 框架稳定性与测试契约

中文 | [English](framework-stability.md) · [返回文档索引](README.md)

本文说明 `mindie-agent-cc` 的日常使用持久性、跨平台配置原子读写与确定性测试契约。

## 1. 日常使用与持久选择

- 安装后的首次配置保存用户的社区贡献选择与项目范围；该选择跨任务、子任务、重启与插件更新持久有效，日常使用无需重复激活或收尾。
- 关闭社区贡献时，框架不执行 `Stop` 采集或小模型整理调用，而知识检索与 `remote-dev` 远端开发工具依然按需可用。
- 自动故障诊断上报拥有独立的配置开关，不随社区贡献开关隐式开启。

## 2. Windows 原子配置读写

- 共享配置存储结合删除共享（Delete-Sharing）读取与 Windows 原生原子重命名语义，确保并发读取者要么看到完整旧文档、要么看到完整新文档；外部占用导致的写入失败会保留原配置并显式报错，绝不触发重置或死循环重试。

## 3. 确定性测试边界

- 单元与集成测试使用仓库内提交的真实解析器夹具与 `uv.lock` 锁定的精确组件提交，不探测或修改用户本机的生产环境安装。
